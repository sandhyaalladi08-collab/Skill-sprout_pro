# Course Feedback Analyzer

A course feedback management and analysis project with a standalone Python CLI, a Python FastAPI service, and a React + TypeScript web interface.

Start here: **[SUBMISSION_GUIDE.md](SUBMISSION_GUIDE.md)** for setup, test commands, a suggested live demo, and the submission checklist.

- Python terminal application: [`cli/README.md`](cli/README.md)
- Python REST API: [`backend/README.md`](backend/README.md)
- Full project notes: [`PROJECT_DOCUMENTATION.md`](PROJECT_DOCUMENTATION.md)

The CLI, API and web interface are separate application layers; see the submission guide for the exact integration boundary. Do not include local `.env` files in a submission.
